# Examples / 示例

Small examples are organized by the version whose public API they use.

小型示例按照所使用的版本 API 分类。

```text
examples/
└── V2/
    └── MHD_Example_V2.py
```

The V2 file is preserved byte-for-byte from the historical repository. Larger model and dataset validation belongs under `experiments/`, not here.

V2 示例按历史仓库原样保留。依赖模型或数据集的完整验证放在 `experiments/`，不与最小示例混放。
